# PRD v0.2 — 研刻 YanKe

> 2026-10-21 对齐新需求。第 3.4 / 3.5 节产品歧义待回复；架构与 Schema 在正式阶段细化。

## 1. 产品定义
面向考研备考人的极简时间表 + 地点约束打卡工具。
核心：周网格时间表 → 计划可选绑定地点围栏 → 到达后打卡 → 记录学习时长 → 完成后写小总结。

核心场景：打开即见本周时间表，空白格点击创建“9:00–11:00 数学”，可选绑定“图书馆 半径200m”。到达后在计划块打卡；结束后点“完成并写总结”，统计页查看科目累计时长与连续打卡天数。

## 2. 核心对象模型
- Plan（计划）：中心对象。字段见 docs/schema.sql
- CheckIn（打卡）：必须附着于某个 Plan，不能独立存在
- Geofence（围栏）：Plan 的内嵌属性，每计划最多一个；不同计划可用不同地点，从而支持多地点
- User：第一周仅本人数据；社交只记候选 backlog，未自动排期

## 3. 页面与流程

### 3.1 时间表主页（P0）
- 周网格：横轴周一至周日，纵轴 8:00–23:00，30 分钟最小刻度，每小时主线
- 今日列头主题色加粗；当前时间细横线贯穿当天列
- 计划块：圆角矩形，科目低饱和色，文字仅“科目 + 时间”；完成后变暗打勾
- 点击空白格直接创建；点击计划块展开底部面板
- 底部面板操作：编辑时间、可选绑定地点、打卡、完成并写总结、删除
- 空状态文案：点击任意空白格，创建你的第一个学习计划

### 3.2 创建/编辑计划（P0）
- 点击空白格 → 底部面板预填时间
- 字段：科目（数学/英语/政治/专业课/其他）、标题（可选）、开始/结束时间、绑定地点开关
- 自定义科目、每周重复、复制 / 顺延只记候选，不阻塞第一周
- 结束必须晚于开始，最短 15 分钟
- 计划重叠：允许保存，视觉错位 + 轻提示

### 3.3 选点与围栏（P0）
- 选点页经鉴权服务端代理调用高德 POI 搜索，Web 服务 Key 不进入客户端；地图交互按选型验证落实
- 半径滑块 50–1000m，默认 200m
- 客户端围栏判断：获取经纬度 → Haversine 距离 → ≤半径允许打卡
- 仅保存围栏中心、半径、地点名，不保存轨迹
- 定位失败提示，不伪造打卡

### 3.4 打卡（P0）
- 入口在计划底部面板；无围栏只看时间，有围栏还需在范围内
- 建议实时窗口为 `[开始前15分钟, 结束)`，normal / late 边界待确认
- 待确认建议：开始前15分钟至开始时刻（含）为 normal；开始后至结束前为 late，无宽限
- makeup：结束后 7 天内补卡，手填时长和总结，无需定位；截止边界在正式阶段明确
- 不设“请假”；休息就不创建计划
- 第一周不做防作弊、不做离开自动结束、不做后台持续定位

### 3.5 完成与总结（P0）
- 用户手动点“完成并写总结”，不自动弹窗
- 手动写自由文本，提示“今天学了哪些知识点？”；必填还是可选待确认（新需求建议必填，旧版可选）
- 顺延为候选 backlog

### 3.6 学习时长统计（P0）
| 场景 | 规则 |
|---|---|
| 正常打卡 | 取计划时长（结束−开始） |
| 提前打卡 | 取计划时长，不膨胀 |
| 迟到打卡 | 实际打卡至计划结束；结束后禁止实时打卡，改走补卡 |
| 补卡 | 用户手动输入分钟数 |
| 未打卡手动完成 | 不计入打卡时长，仅计完成 |

统计页：按科目累计时长、完成率（完成计划数/计划总数）、连续打卡天数。不做复杂图表。

### 3.7 登录（P0）
- 第一周邮箱 + 密码；邮箱确认依 Supabase 配置，邮箱验证码登录不作前置，不做手机号
- 支持退出、注销账号

### 3.8 通知（候选 backlog）
- 本地通知非第一周核心前置，远程推送不在第一周范围

### 3.9 好友与动态（候选 backlog，未排期）
- 加好友（搜索邮箱/昵称）、好友可见帖子（文字+照片）、评论
- 不匿名；不做公开广场、不做圈子
- 上架前必须补举报/拉黑与基础审核

### 3.10 后台管理
- MVP：Supabase Studio；统计视图必须尊重 RLS，不单独开发后台
- P1：极简 Web 后台

## 4. 异常与边界
- 无网络：时间表读本地缓存，写操作提示稍后重试
- 定位权限拒绝：引导系统设置，绑定地点的计划无法打卡
- 计划重叠：允许，错位 + 轻提示
- 跨天计划：第一周不支持
- 时区：设备本地时区
- 打卡后删除计划：保留打卡记录，统计计入历史

## 5. 验收标准
1. 创建计划：点击空白格填 9:00–11:00 数学保存 → 网格对应位置出现数学色块，重启后仍在
2. 绑定地点：开启绑定，搜索“图书馆”设 200m 保存 → 计划详情显示地点与半径
3. 围栏内打卡：距离≤200m 且在时间窗口 → 生成打卡，类型 normal 或 late
4. 围栏外打卡：距离>200m → 提示未到达，不生成记录
5. 补卡：计划结束 3 天未打卡 → 补卡输入 90 分钟 → 记录 makeup，统计 +90
6. 完成总结：已打卡 → 完成并写总结保存 → 色块变暗打勾，详情可见总结
7. 统计：本周数学正常打卡两次各 120 分钟 → 数学累计 240，连续打卡天数正确
8. 登录：新用户邮箱注册登录 → 进入时间表；未登录跳转登录页
