## 代码审查

- 查询 / 编辑 / 软删均限制本人 ID，查询排除 deleted。创建使用一次生成的 UUID，失败重试复用同一 ID；唯一冲突后只更新本人同 ID 且非删除的行，避免不确定响应导致第二条计划或复活软删对象。已有计划编辑不更新冻结时区、状态、总结或围栏字段。
- 表单按计划创建时的 IANA 时区解释，转换后进行本地日期 / 时间往返验证，拒绝不存在的日期、无效时区及跳过日。限制同日08:00–23:00、至少15分钟；标题修剪后按字符上限检查。
- `AuthGate` 用 scope key 卸载旧用户页面，旧 scope 立即失效。周查询使用 effect active 标记、请求 generation 和 scope 三层保护；渲染再按当前 range 筛选结果。切周不显示旧范围，刷新 / 保存使旧查询失效，成功写入随后重新加载；请求失败保留可用同周内容及重试入口。
- 编辑器有同步 pending 标记及 busy UI，防止重复点击；失败保留 draft，异步回调检查 mounted / scope。软删保留打卡历史，有二次删除确认。重叠允许保存，计划列表为重叠块提供独立可访问入口。
- 当前周在午夜及 App 重新激活时更新；前后周、回本周、半小时新建预填与 timegrid 事件选中接线完整。新增业务没有扩展到打卡、定位、围栏编辑或统计。
